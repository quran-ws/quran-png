quran-canva

The mushaf, inside the Canva editor

The website works, but the loop is clumsy: leave your design, pick an ayah, download a file, go back, upload it. quran-canva is the same picker running in Canva's side panel. Choose a surah and a range, press Add to design, and the ayah lands on the page as a transparent image you can move, scale and recolour like anything else.

Status

The app is built and pending Canva's marketplace review. Until it is listed, the web generator does everything the app does — the app only removes the download-and-upload step.

What it can and cannot do

It inserts a transparent PNG at 3000 px, which is enough for any print size a Canva design reaches. Canva resizes it like any image, and because the background is transparent it sits on any colour. What it does not do is make the verse editable text — that is the point. Editable Arabic text is precisely what breaks the mushaf's ligatures and diacritics; the image is the guarantee that the ayah is rendered as the Complex prints it.

It reads nothing

The app asks for no permissions and no account. It calls one public, unauthenticated endpoint for the surah list, and hands Canva an image URL. It cannot read your designs, and there is nothing for it to store about you.

Built on the same public API this site uses.
