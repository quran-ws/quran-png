Support

Getting help

Write to support@quran.ws. If something rendered wrongly, include the surah and ayah range and the address of the image, and we can reproduce it exactly.

Using the Canva app

Open the Apps panel in the Canva editor and search for Quran Mushaf. Choose a surah and a range of ayahs, pick a layout, then select Add to design. The verses arrive as a transparent image you can move and resize like any other element.

If the panel stays empty or the preview does not appear, it usually means the request to this service could not complete — check your connection and reopen the app.

Choosing a layout

Mushaf lines keeps the line breaks of the printed page, exactly as the muṣḥaf sets them. Fit to width repacks the same words, at the same size, into justified lines filling the shape you choose. Neither one stretches or distorts a letter, which is why a long range in a narrow shape becomes taller rather than tighter.

Print quality

The artwork is vector, so it does not blur when enlarged. On the website you can raise the pixel width, or download the same range as a vector or as a document for print. The Canva app inserts at a width generous enough for any print size a Canva design reaches.

Reporting an error in the text

The text is the King Fahd Complex's own printed plate artwork, so the letters and marks are theirs rather than ours. If a word looks wrong, misplaced or missing, please tell us — that is a fault in how we cut or placed the artwork, and we want to know.
