API

One URL is the whole API

Every image is a GET request you can paste into a browser, an <img> tag, or a build script. No key, no signup. Responses are immutable and cached forever, so you can hotlink them.

$ curl -O "https://png.quran.ws/api/v1/image/2/255.png?layout=fit&aspect=post&width=3000"

surah 2·ayah 255·4:5 portrait·3000 px wide·transparent

Path

GET /api/v1/image/{surah}/{range}.{format}
/2/255.png one ayah
/18/1-10.svg a range, as vectors
/112/1-.pdf to the end of the surah, print-ready
